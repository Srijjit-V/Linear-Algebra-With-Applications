# Linear Algebra With Applications

Coursework for BIS 231 (Linear Algebra with Applications) at UW Bothell — lecture
notebooks plus my completed homework, covering the linear algebra foundations
behind common ML methods.

## Topics

- Vectors & matrices, vector visualization and operations
- Exploratory data analysis
- K-means clustering (from scratch, then with scikit-learn)
- Matrix algebra & linear dynamical systems
- Systems of equations & inverse matrices
- Least squares
- Regression models (from scratch, then with scikit-learn)
- Training models with gradient descent

## Structure

```
notebooks/   Lecture and homework notebooks (Jupyter)
datasets/    CSVs used across the notebooks (college, iris, penguins)
```
